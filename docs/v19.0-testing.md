## Source decision

Debian Trixie does not publish an installable `xoops` package. The appliance
therefore uses the official XOOPS Core 2.7 stable release. Version 2.7.3 is
pinned to commit `00fff34c11fd4bee606e734d3bccf52d36fe0fda`; its downloaded
commit archive must match SHA256
`b49d935116352434a60e5dae93efce356d9e5f360ad92bc72dcc69d7ab82b8cb`.
The official project publishes stable releases, an explicit latest-version
security policy, and `security@xoops.org` for vulnerability reports.

## Update contract

`turnkey-xoops-update --check` identifies the installed source and resolves the
latest official, non-prerelease XOOPS 2.7 tag to its exact upstream commit.
`--apply --dry-run` exposes the same version, tag, and commit without changing
the installation. A supervised `--apply` creates database and file backups,
copies only official release code while preserving `mainfile.php`, uploads,
external data, and generated credentials, then places the official upgrader at
`/upgrade/`. The administrator completes the upstream database and module
steps in the browser, as required by XOOPS release documentation.

## Deferred issues

- MEDIUM: The official non-prerelease `v2.7.3` tag still declares the runtime
  string `XOOPS 2.7.3-RC1` in `include/version.php`. The appliance records both
  identities and binds them to the same official commit. This affects version
  display, not the tested administrator, content, database, or updater flow.
- MEDIUM: The updater cannot complete XOOPS database and module migrations
  without the administrator's authenticated browser session. It stages the
  official upgrader and preserves a backup; fully unattended application
  upgrades are outside the upstream-supported flow.

## Loop accounting

Product loops begin at zero. Only a reproduced main-flow appliance defect or a
HIGH issue reachable in a normal supported deployment consumes the three-loop
ceiling. Source checks, test corrections, builder queue failures, retained
evidence updates, and the known shared cleanup dependency failure consume zero
product loops.
